# AutoEdge — 自动描边工具

**本项目由 AI 辅助开发。**

## 使用说明

## 一、安装与启动

1. 解压 `AutoEdge-1.0.0-win64.zip`；
2. 双击 `AutoEdge\AutoEdge.exe`。

## 二、操作流程

1. 左上角打开图片
2. 点「**圈定区域**」按钮，圈出一个或多个需要描边的晶体
3. 点「**绿点：这里是晶体**」，添加一个或多个点作为晶体参考点；点「***红点：这里不是晶体**」，添加一个或多个点作为基底参考点
4. 调整描边阈值，阈值越小会把色差小的分界也当做晶体边缘，反之亦然，如有需要可自行调整高级选项（最小面积：低于此面积的碎晶不会被圈进去；简化容差：将低于此大小的锯齿边画为直线。这两个选项一般不需要动）。阈值参考数据：明显分界的厚晶体30-60，薄晶体10-20，单层3-6，根据实际情况自行调整。
5. 根据需要自行调整线条样式。
6. 点击预览，观察描边情况，根据需要修改参数重新预览。
7. （可选）如果对自动描边结果不满意，可以手动编辑。
8. 导出图片。

## 三、进阶操作
## 多图层

右栏是图层面板。**预览与输出是所有"可见图层"的叠加。**

**每个图层的设置参数和预览效果各自独立，最终渲染效果为叠加**
用处：先把厚的晶体用高阈值描好，再新建图层，重新选区用低阈值描薄层。

## 预设

根据需要可保存描边参数和线条参数的预设。
